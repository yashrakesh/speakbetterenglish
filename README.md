# AI English Communication Coach (Completely Free)

This project validates a conversational English coaching product without any paid infrastructure.

## Free Architecture

- Static frontend only (HTML/CSS/JS)
- No OpenAI API calls
- No backend server
- No database
- No login/auth
- No payments
- User uses ChatGPT directly by pasting the provided system prompt

## What Users Do

1. Open the page.
2. Click `Copy System Prompt`.
3. Click `Open ChatGPT`.
4. Paste the prompt as first message.
5. Start real conversation practice with text or voice.

## Local Demo Included

The page also includes an optional local simulator chat that demonstrates the same coaching loop without calling any API.

## Deploy for Free

### GitHub Pages

1. Push files to a GitHub repository.
2. Go to Settings -> Pages.
3. Set source to `main` branch, root folder.
4. Save and use the generated Pages URL.

### Netlify

1. Import repo in Netlify.
2. Build command: none.
3. Publish directory: root.
4. Deploy.
